# TailAdmin 页面映射与实施范围

更新：2026-09-11。依据：[PRD](../batch-era/PRD-20260913.md)、D14/D15。已采用 **TailAdmin Next.js Free 2.3.0（MIT）＋自建业务页面**，应用位于 `apps/web`，入口为 [今日经营](http://127.0.0.1:5198/overview)。

七个路由已经实现前端交互，业务数据与执行使用本地模拟。模板提供视觉和基础组件；具体经营状态、会话、机会、历史接续及 Agent 设置由本项目实现。当前没有真实认证、数据库、模型或平台连接器。

## 当前导航

| 入口与路由 | 包含功能视图 | 日常使用方式 |
| --- | --- | --- |
| 今日经营 `/overview` | 01 总览；11 决定汇总 | 查看已推进、正在等待和需要人决定的事情，下钻到具体合作 |
| 经营目标 `/goals` | 02 目标与策略 | 配置市场、方向与边界；预览、保存版本、启用与暂停 |
| 机会与货盘 `/opportunities` | 03 商品/Offer；04 一发；05 二发；06 机会池 | 页内切换来源和准备状态，按同人与商品归并合作事项 |
| 合作工作台 `/workspace` | 07 关系会话；08 链接/样品；11 个案决定 | 处理一人多事项，人工接管、交还、核验与结果事件 |
| 效果与质量 `/results` | 14 效果、费用与质量 | 查看模拟覆盖、回复与采用等不同阶段，不合并冒充收益 |
| Agent 与知识 `/agents` | 09 话术；10 知识/历史；12 Agent/Skills | 调整职责和策略、预览三市场消息，核实并接续 MX 历史，运行本地回放 |
| 系统设置 `/settings` | 13 资源、连接与运行 | 配置演示资源参数，查看渠道尚未接入的状态和接入准备 |

MX/BR/IT 市场是共享范围。商品、机会、关系和事项是不同对象；导航归组不改变各自业务状态。全局包含搜索、最近动态、主题、体验流程和重置演示。

| 06 机会池与关系协调 F05 | 同人同商品一发/二发归并、详情抽屉、待准备视图与已有事项跳转 | 跨来源身份解析、数据库唯一约束、并发租约与队列 |
| 07 合作工作台 F07/F08/F10 | 自建关系列表、会话、商品事项、证据面板；接管/交还、人工消息和内部备注 | 监听补回、远端身份、真实消息/附件、关系控制持久化 |
| 08 链接与样品事项 F08 | 会话内展示请求、商品卡/入口与状态；可模拟接收、未知核验和后续结果 | 实际链接/样品查询与动作权限、回执及物流证据，不从模拟状态推导批准或建链 |
| 09 个性化话术 F06 | `/agents` 话术策略：固定正文、骨架改写、策略生成；三市场示例预览和版本 | 真实模型调用、逐事实约束、翻译/生成质量与费用记录 |
| 10 知识与 MX 历史 F09 | 历史并列分类、当前核实、可行动历史接回合作；核实不发信 | 原消息导入、来源时点、业务认可案例、脱敏与知识版本管理 |
| 11 需要人决定 F10 | 总览入口与会话详情：当前请求、事实、方案、影响与范围；决定后状态更新 | 生产权限、决策审计、外部执行确认与并发控制 |
| 12 Agent 与 Skills F12 | 职责与能力配置、策略版本、按需协作说明、本地离线回放 | 真正运行框架、业务 Skill 包、工具权限、模型版本、评估发布/回滚 |
| 13 运行、连接与迁入 F11/F14 | `/settings` 参数表单、MX/BR/IT 渠道状态与接入准备；通知展示模拟事件 | 账号能力、预算计量、耐久任务、源水位、迁入和唯一执行归属 |
| 14 效果、费用与质量 F13 | `/results` 模拟指标、趋势和阶段分离；采用与接收分别记录 | 真实归因、内容/样品/订单证据、费用计量与质量评估 |

## 先前研究的保留结论

免费仓库提供电商总览、基础表格/表单、图表、认证表单和 UI 元素；Pro Demo 的 CRM、Chat、商品管理、任务管理、AI Settings 等页面不是免费源码的一部分。选型时读取公开 Demo 的22个相关路由得到 HTTP 200，只证明演示路径存在，不证明产品后台或客户端交互。

现已选择免费加自建，Pro 内部文件名、购买档位与交付包不再是实施依赖；没有复制 Pro 源码。先前价格及许可原文留在[许可研究](../../research/tailadmin-license-review.md)，不会作为当前待确认事项反复询问。

视觉和交互验收以根目录 `design-qa.md` 的截图、实际视口与操作记录为准，不能以本表的实现映射替代验收。
