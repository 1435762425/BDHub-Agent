## 撤销的旧预设

- 固定三个自主 Agent 不再作为架构前提。业务责任、执行隔离和评估保留，角色数量依证据决定。
- “旧项目已用 Pydantic AI，所以新系统继续用”不成立；它只是比较候选之一。
- “PostgreSQL 自建队列一定最简单”不成立；需与成熟耐久层的整体维护成本比较。
- “换到服务器自然就能扩大触达”不成立；平台额度、连接器和服务承载常常是瓶颈。
- 旧同仓方案、旧蓝紫/石墨生成 UI 不自动继承；此前工作保留为历史参考而不进入默认新上下文。
