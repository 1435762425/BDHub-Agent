# Kalodata 网页可见字段清单

日期：2026-09-20。证据来自已登录的 Kalodata Chrome for Testing，市场选择为 TikTok Shop IT、币种 EUR、中文界面。实际查看了商品详情页、商品维度的视频/达人/直播表，以及达人详情页。本文记录网页可见口径；不是根据 BDHub 当前接口字段反推。

## 一、商品基础信息

| 网页字段 | 含义 |
| --- | --- |
| 商品标题 / PID | TikTok Shop 商品及稳定商品ID |
| 发货类型 | 本土或跨境等履约类型 |
| 类目 | 商品所属多级类目 |
| 价格 | 当前页面展示价格 |
| 佣金比例 | 页面观察到的联盟佣金比例 |
| 评分 | 商品评分及满分5分口径 |
| 评论分析 | 对评论内容的分析入口；评论不足时页面会提示 |
| SKU 数量 | 商品变体数量 |
| 商品描述 | 平台商品描述入口 |
| 店铺名称 / 店铺类型 | 商品所属店铺及品牌店、零售商、本土店、跨境店等标签 |
| 数据最早收录时间 | Kalodata 首次观察该对象的日期，不是商品上架时间的同义词 |
| 商品属性 / 卖点 | 品牌、类型、材质、功效、使用方式等结构化属性及提炼卖点 |

## 二、商品核心指标

所有指标受页面日期范围控制，并同时展示区间总量及部分指标的每日均值。

| 网页字段 | 含义 |
| --- | --- |
| 成交金额 | 选择时间范围内该商品 GMV |
| 销量 | 选择时间范围内售出件数 |
| 平均销售价 | 成交金额与销量形成的平均成交单价 |
| 直播成交 | 归因于直播的 GMV |
| 视频成交 | 归因于短视频的 GMV |
| 商品卡 | 未归因到视频或直播、由商品卡等入口产生的 GMV |
| 达人出单率 | Kalodata 展示的达人出单比例；网页可访问文本没有给出精确分母公式，不能自行固化计算口径 |
| 近30天达销集中度 | 销售在达人之间的集中度；网页未展示精确公式，不能直接假设为 Top N GMV 占比 |
| 销售策略 | 总 GMV 按直播、视频、商品卡拆分的金额与比例 |
| GMV 趋势 | 所选时间范围内按日变化的成交金额曲线 |

## 三、商品维度明细表

### 视频与广告

| 网页字段 | 含义 |
| --- | --- |
| 视频内容 | 封面/文本、视频时长及 AI、AD 等标签 |
| 成交金额 | 该视频归因 GMV |
| 观看次数 | 视频播放量 |
| 销量 | 该视频归因销量 |
| 发布日期 | 视频发布时间 |

### 达人

| 网页字段 | 含义 |
| --- | --- |
| 达人信息 | handle、头像等身份入口 |
| 粉丝数 | 达人当前或页面观察到的粉丝规模 |
| 成交金额 | 该达人为当前 PID 在所选窗口贡献的总 GMV |
| 销量 | 该达人为当前 PID 在所选窗口贡献的件数 |
| 视频成交 | 该达人通过视频为当前 PID 贡献的 GMV |
| 直播成交 | 该达人通过直播为当前 PID 贡献的 GMV |

这张表就是当前 PID→达人线索抓取的网页对应物。Kalodata 页面中同一 IT PID 的金额统一显示为 EUR。

### 直播

| 网页字段 | 含义 |
| --- | --- |
| 直播内容 / 达人 | 直播间与主播信息，可标记是否有录像/片段 |
| 直播时间 / 时长 | 开始结束时间与持续时长 |
| 成交金额 | 单场直播归因 GMV |
| 销量 | 单场直播归因件数 |
| 平均销售价 | 单场直播成交均价 |

## 四、达人详情页

### 达人基础与核心指标

| 网页字段 | 含义 |
| --- | --- |
| handle / 简介 | TikTok 达人身份和公开简介 |
| 签约/可联系合作标签 | Kalodata 对合作状态或联系能力的页面标签，不等于 BDHub 已获得联系授权 |
| 首次发布视频时间 | 页面观察到的最早视频发布时间 |
| 粉丝数 / 粉丝画像 | 粉丝规模，以及性别、年龄、前5地区、前5语言、活跃时间等画像入口 |
| 近30天带货数量 | 最近30天带货商品数量 |
| 数据最早收录时间 | Kalodata 首次观察该达人的时间 |
| 成交金额 | 达人在选定店铺/类目/窗口内的总GMV |
| 直播成交 / 视频成交 / 橱窗及其他成交 | 达人GMV按渠道拆分 |
| 平均销售价 | 达人带货商品的平均成交单价 |
| 直播观看次数 / 视频观看次数 | 对应内容类型的观看量 |
| 粉丝数变化量 | 所选窗口内粉丝增减 |

### 达人店铺、视频、商品和直播表

| 页面 | 网页字段 |
| --- | --- |
| 店铺 | 店铺信息/类型、成交金额、商品数量、销量 |
| 视频与广告 | 视频、关联商品、成交金额、观看次数、广告成交占比、广告观看占比、广告消耗、广告 ROAS、发布日期 |
| 商品 | 商品信息、发货方式、成交金额、销量、平均销售价 |
| 直播 | 直播间信息、直播时间、成交金额、观看次数、千次观看成交金额 |

## 五、当前 BDHub 实际抓取范围

当前 PID→达人列表只保存以下 8 个 Kalodata 原始字段：

| 当前字段 | 网页对应含义 |
| --- | --- |
| `id` | Kalodata creator ID |
| `handle` | 达人 TikTok handle |
| `nickname` | 达人昵称 |
| `sale` | 当前 PID、当前窗口内的销量 |
| `revenue` | 当前 PID、当前窗口内的总 GMV |
| `video_revenue` | 当前 PID、当前窗口内的视频 GMV |
| `live_revenue` | 当前 PID、当前窗口内的直播 GMV |
| `followers` | 粉丝数 |

因此当前没有抓取：商品卡 GMV、达人出单率、达销集中度、平均销售价、视频观看量、广告指标、达人整体GMV、粉丝变化、店铺/商品/直播明细、粉丝画像等。

## 六、对 BDHub 的建议

1. PID 二发排序所需的核心字段已经存在：稳定达人身份、`sale`、总/视频/直播 GMV 和平台 `revenue DESC` 名次。
2. 下一版可把 `revenue` 三项解析为精确 EUR 数值，并把 `region=IT / currency=EUR / windowStart / windowEnd / observedAt` 一起冻结；旧混币批次必须刷新后才能参与绝对 GMV 横向比较。
3. 商品卡 GMV可以补充为渠道归因字段，但不应改变“`sale>0` 才形成线索”的现行资格规则，除非用户另行修改。
4. 视频观看量、广告消耗/ROAS、粉丝画像适合后续匹配与内容研究，不是二发发送资格的必要字段。
5. `达人出单率`和`达销集中度`在没有官方公式前只保存平台观察值，不自行重算或用于硬门禁。
