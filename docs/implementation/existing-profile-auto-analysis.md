# 根据已有画像自动分析

2026-09-12。按用户最新要求：忽略画像年龄；价格带、内容形式暂不作为主要依据；依据已有画像自动分析并自行完成测试，人工标注不是推进前提。此规则覆盖此前“一发先等待画像刷新或人工判断”的实施建议。真实发送仍关闭。

入口：[画像分析](http://127.0.0.1:5198/opportunities?mode=matching&dataset=italy-profiles)。保持原数据集和独立数据库，已有来源、召回和人工记录不删除。

## 数据实际补齐

上一版只读取导出中的单一主类目。此次直接只读查询旧系统的`creator_profile_snapshot`，严格限定原3,978个OEC及对应观测时段，核对每人唯一accepted快照、采集时间和原GMV。连接确认`transaction_read_only=on`，15秒语句超时，没有远端采集、业务写入或凭证复制。

新增允许字段：全部具名类目、粉丝、成交件数、平均播放、GMV及其原始符号、统计截止时间、来源快照编号。

- 共13,104条来源类目项，其中9,871条具名、27个原文类目；3,233条`-1`未知类目保留在本地源文件，不补名称、不重新归一化权重。
- 原类目权重在0–1之间，但没有证据证明是GMV、订单或内容份额；本轮不把权重当成交份额或评分权重。
- 粉丝、成交件数、平均播放、GMV均有3,978条记录；109条平均播放为已观测0，不当缺失。
- GMV原始符号全部为`€`且市场为IT，保留EUR十进制原值。来源统计截止为2026-07-28，起点未提供，不宣称“近30天”。GMV和粉丝用于理解规模，本轮不进入主要排序。

英文标签按显式映射进入已有中文顶级类目空间，保留原名与转换版本；`Modest Fashion`原名保留，不推断成宗教类别。原来清新片与枕头分类的冲突仍隔离，忽略年龄不等于忽略矛盾事实。

## 自动分析与排序

`profile-first-v1`按明确需求、精确同品证据、共同类目数量依次比较；同来源统计口径和指标可用性组内，再按成交件数、平均播放排序。不同来源或未知指标分组交错展示，不把未知值当0，也不根据粉丝或GMV虚构成功概率。

类目索引在取前200个候选之前排序，修复先按ID截断导致强候选永远漏出的情况；测试已覆盖ID排在第260位的高表现候选进入首位。最终每次最多50个，界面默认20个。系统没有把商品×达人所有组合逐对交给模型。

每个候选自动生成`analysis`：结论层级、事实依据、必要边界和画像摘要；原`readiness`仅表达执行准备。画像年龄、缺价格带或形式不产生分析阻塞；身份、拒联、暂停、Offer和平台执行仍独立处理。人工判断保留为可选反馈，系统不写成用户认可。
