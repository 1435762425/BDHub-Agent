## 新规则与旧链接

新配置`config/catalog-link-policy.json`：机构至少1、优先2个百分点，达人至少比公开高1个百分点。差值恰好2时，机构留1、达人提高1；差值≥3时机构留2。精确百分比运算和平台单位转换已实现，不用旧版固定留2导致达人没有升佣优势。

新旧链接使用判定独立：旧链接只有当前平台有效、商品合格、达人>公开、机构≥1才可复用；最高达人佣金优先，同佣金优先已有使用记录。不因旧分配与新规则不同而重新建链。

上述旧链判定和排序已有纯逻辑测试。本次单品入口遇到任何已有卡片就保留并进入旧链复用审查，不自动重建；完整平台旧链扫描、有效性核验与自动选择仍待批量模块接通。不能把单品入口的“保留已有卡”称为整个自动复用流程已完成。

## 可恢复意图与隔离

`var/catalog-links.sqlite`保存货盘级`catalog_link_intent`，不等待某个二发任务凑齐达人名单。业务键包含PID、市场、来源、活动、达人点位、规则版本和账号，不包含观测时间；同一业务计划重复准备得到同一意图。

状态为prepared → submitted → receipt_saved → verified；提交或回执不明进入unknown，后续只读核验，禁止盲目第二次创建。创建前重查商品初筛、已选活动、佣金、期限和旧链存在性；计划变化不偷偷修改提交参数。全托不检查库存数量。
