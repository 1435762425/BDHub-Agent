# 巴西一发与样品审批

2026-10-23（Asia/Shanghai）。用户确认的规则见 [PROJECT §4.4](../PROJECT.md#44-巴西一发与样品审批)，模块入口见 [TECHNICAL](../TECHNICAL.md)。本说明区分代码交付与真实平台验收。

## 使用方式

打开 `/br/first-outreach`。首次需要同步商品和样品记录，再准备匹配。准备任务使用现有巴西达人库，完整发布后可查看候选、商品与葡语邀请。页面“验证首条”只授权一位达人；卡片与文字均回查确认后自动停止，之后由“继续持续推送”开启持续执行。停止推送与自动审批使用各自控制；关闭自动审批不改变已提交请求的结果。

一发与二发共用原达人关系及投递账本，不能通过换商品、执行器或来源绕过冷却、拒联、人工接管、来信或未知隔离。准备匹配及来源刷新不联系达人。重复同一页面请求复用原任务；中断后从原请求、阶段与达人游标恢复。

## 平台事实与缺口

已使用本项目 BR 供给账号 acc2，在既有 ProfileLease 下只读核对已加入活动首屏、首个活动商品首屏和历史已验样品过滤首屏。真实商品行返回 `sample_quota`，本次五条均为零，没有一级类目字段。该样品过滤返回 total=0，省略空 `sample_records`。证据在 `var/first-outreach-readonly-20261023.json`，不入 Git。

空样品响应不能证明当前待审批的范围、平台 creator_id 与 OEC 的对应、机构付款字段或审批生命周期。审批路径已列于 [接口合同](../contracts/tiktok/business-catalog.md#tk-010-批准或拒绝样品申请)，本次没有真实审批。`sample_review_contract_unverified` 明确阻止新审批；读取成功不自动提升审批能力。后续须从真实 BR 申请和单条审批回读取得这些证据，再登记当前账号绑定的合同与能力。不得用 MX 字段枚举、人工填成功或合成测试解除该门禁。

浏览器工具本次禁止访问当前 URL，浏览器核验已终止；上述请求使用项目原有、已文档化的业务读取接口，没有通过其他方式读取受限网页。

## 验证与运行边界

离线测试使用临时 SQLite、伪平台与伪模型，覆盖主营类目、金额精度、最新未授权、分页完整性、断点恢复、首条授权、混搭模式、暂停、跨一发二发冷却、重复申请、并发样品预留、付款未知、结果 unknown 与商家待确认。Web 验证固定 argv、市场隔离、本机来源限制、严格状态白名单、build 后 typecheck。

真实推送、审批与合作结果需单独验收；代码测试或页面上线不替代平台回执。既有调度、二发、收信和 AI 回复的授权与常驻进程不因本功能代码交付自动改变。当前发布与运行状态记录于 [handoff](../handoff/current.md)。
