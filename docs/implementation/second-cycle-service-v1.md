## 已实现

- 301历史读取可显式导出正文，默认仍不导出；事件身份结构保持兼容。只把creatorReplies的正文/附件标记存入本机版本表，保留原始hash和内容版本，不在日志保存正文或认证信息。图片/未知类型不当作空文字，不自动下载媒体。
- 首次历史补录不创建回复任务；新回复60秒合并。迟到内容可以补入既有事件；同ID正文变化保留旧版本、使旧判断失效，已解决消息被编辑时重开处理水位。
- 当前规则初筛覆盖明确拒联、链接故障、更多目录/链接、退款样品、补样、索样、佣金、Boost、多诉求和简单致谢。拒联标记不因人工交还而解除；索样不变成机构批准样品；佣金转needs_facts并要求当前达人佣金查询。
- 人工事项同一未结关系归并，显示原话、原因、消息版本和24小时超时。处理结果必填，提交时同时核对入站版本及关系控制版本；有新消息则拒绝旧版交还。结果持久化，重复同结果幂等；已处理旧问题不反复进入下一轮。
- 本地API /api/cycle-service：GET查看，POST只接受resolve；来源校验、输入体积和字段限制，不提供发送或样品批准能力。工作台“达人咨询 · 人工接续”展示真实数据。

## AI分类验证

service_agent_evaluation为独立影子评估记录，最多3条、每条2000字；只提供当前必要的入站文字，不提供内部总佣金、Cookie或完整历史库。模型只允许输出分类、原文证据和允许的工具ID，不能加回复正文、授权或执行动作。结果必须可由原文片段验证；未知请求不能重复调用，已保存响应可离线解析恢复。

一条真实意大利历史回复表达“已添加，还想要其他申请样品的链接”。AI判multiple_requests，简单规则最初只判索样；已补“其他链接/商品”识别与多诉求回归。实际模型调用1次，共317 tokens；再次运行命中缓存，不调用模型。该历史消息没有生成待办或触发回复。

## 运行边界

当前自动运行的是正文采集和规则路由；AI分类仅完成历史影子验证，未替代在线决策。确认句ack_state=not_sent明确展示：本轮没有代表公司回复“已交人工”，不会让用户误以为已发。图片只保存类型/hash及原会话标记，原媒体查看与视觉理解尚未接通；尚无原会话直接跳转按钮。

已注册两个只读回复工具：get_relationship_product_context和get_current_creator_commission。前者只认已确认投递的商品卡，多PID上下文保持歧义；后者按绑定卡实时查询，返回达人佣金及来源，不提供机构佣金。咨询needs_facts由周期任务查询并转facts_ready_for_review；查询期间消息或控制版本改变则不采纳结果。样品/补样仍停policy_review。下一步形成版本绑定的答复/确认句意图与执行器，不能把影子模型输出直接接发送。
