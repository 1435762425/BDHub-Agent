# 任务级整批采集与商品材料准备

2026-09-14，接续[任务卡与本地检查](batch-task-cards-v1.md)。本轮用户指定首个意大利批次目标 **1000 位＋100 位候补**；开始日期与北京时间窗口仍待用户提供。没有把历史 3000／5000 示例创建成真实任务。

## 本轮实现

- 新 `batch_source_plan/job/page` 台账独立于旧 `source_job`，不写原计划 capacity，不从账号数推导新联系额度。按全部目标缺口一次规划足量 PID（每 PID 10 人是规划估计，不计作就绪），不是每轮只准备 5 个 PID。1000 人加候补、已有 101 候选时，规划估计为 100 个 PID；实际不足继续在原范围补足，整批完成前不进入发送。
- 采集复用旧版已验证 Kalodata HTTP 登录与查询协议：意大利、14 日区间、两日数据滞后、每页 50 行，默认每 PID 最多两页。窗口冻结在任务的首次准备计划，不随每天重启变化；两页上限标为 page_cap，不冒充已穷尽该商品所有达人。
- 每页先持久化响应证据，再导入新项目共享来源库；中断后的回放不重复请求已保存页或改写已有事实。查询租约带 fence，旧请求不能覆盖新进程进度。重复页、业务拒绝、认证失效分别记录；认证失效停止该任务其他 PID 请求，更新登录后人工暂停／继续可重试。
- 只将本任务来源交给身份队列；精确 Find 与 OEC 证据沿用已验证身份链路。`IdentityBridge` 新增可选 source_ids/outbox_ids，旧调用保持原行为。任务级 handoff 中断后能从共享台账恢复关联；空 scope 不变成全量。
- PID 采集完成后等待该 PID 所有身份记录终态，再重新评估真实候选缺口。无法精确匹配的 handle 保留来源，不构造 OEC。
- 全部目标＋候补名单先齐备，再按 `materialKey` 批量准备短名和具体卡片。同标题／语言短名缓存复用，至多五个商品一组调用模型，不逐达人生成话术。
- 已选／已加入活动的商品：定向读取当前佣金、期限、可用性，复用实际匹配的卡片；缺卡时调用原有受控单项建卡协议，并保存任务对创建意图的引用。未知创建优先核验，商品后来离开当前名单也继续核验原意图；不换意图重建。
- 材料就绪需匹配 PID、活动、达人佣金、wire campaign、具体 listId 和回查证据。当前方案指纹改变不能沿用旧材料。所有正式／候补成员通过才冻结为 ready；卡文发送资格仍为 false。
- Worker 持续执行任务准备，HTTP／子进程期间更新心跳；有待采集页时短间隔续接，阻塞和空闲状态较低频检查。页面增加本任务 PID、页数、线索及身份等待／异常统计。

## 确认范围

新任务卡明确展示采集、身份查询、模型短名及已选／活动商品的 TapLink 核验／创建，其策略范围为 `full_preparation_no_messages`。这是准备权限，**不包含私信发送、回复、删除链接或未选全托商品的选入**。

确认 API 必须收到新界面显式的 preparation scope；旧已打开界面不能用旧确认格式启动新增准备动作。原 `local_preparation_only` 任务不会自动升级，新规则令旧未确认卡片失效，需重新展示正确范围。当前 AI 回复手动暂停仍生效。旧试验批次 local_capacity_reached 不恢复。

只写 BDHub-Agent 的台账与证据。旧 BDHub 只读复用配置和协议；Kalodata 锁文件仅只读打开并取得 advisory lock，不写 Cookie。TikTok Reader 继承已验证 HTTP 验证能力，新增白名单只包含 GET 商品卡／成员／活动，不允许借此提交平台写入；建卡由既有独立写协议执行。

## 实测与测试

- 39 项批次测试通过，覆盖 3000→330 个 PID 规划、5000 人限定 PID 不扩范围、分页持久化重启、暂停竞争、登录失败停止后续 PID、fence、重复页、旧权限不升级、同材料多达人、佣金／活动错配、全量冻结及未知不放行。
- 原循环 152 项测试通过，包括新增任务范围身份 handoff 测试；存在历史 fixture ResourceWarnings，无断言失败。
- Next.js 构建和 TypeScript 检查通过。
- 真实 Kalodata 只读 canary：PID 1729480033890900437 一次请求返回 3 条有效带货线索，短页结束；Cookie 文件未变。结果仅进入临时测试台账，没有污染正式任务库或提交身份外部操作。
- 真实 TikTok 只读素材 canary：同 PID 活动／商品卡交叉核验成功，达人佣金 13%，具体 listId 8650227344906885910，`stockRequired=false`；耗时约 3.46 秒，身份文件未变。
- 以上真实 canary 都没有选入、建卡或发送。证据在 `var/batch-source-canary-*.json` 与 `var/batch-material-canary-*.json`。新任务整批自动创建卡片的真实验收仍待运行，不把旧单项写协议的验收当成本批已执行。
