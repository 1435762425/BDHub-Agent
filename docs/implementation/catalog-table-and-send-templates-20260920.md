# 货盘表格化与发送话术多模板

实施日期：2026-09-20。

## 货盘与材料

页面保留“全托商品 / 非全托商品 / 达人线索”三个业务页签和阶段边界，但把原来一排排独立数字卡统一成表格：每行只回答项目、当前数量、判断口径和可用操作。覆盖范围包括总览、流程漏斗、全托采集与筛选、标准链接、Campaign 加入/商品池/链接、达人线索队列、OECID 和发送池。

商品明细、筛除原因、异常和运行进度仍按需展开；执行按钮继续留在对应业务行或阶段容器内。这样减少视觉容器数量，但不合并不同写权限，也不删真实台账字段。

## 发送话术模板

新批次提供五种模板：

| ID | 页面名称 | 用途 |
| --- | --- | --- |
| `standard` | 佣金提升 | 先说明佣金，再邀请短视频或直播 |
| `brief` | 简短直接 | 一句话说明商品、佣金和动作 |
| `reconnect` | 再次合作 | 明确表达同品再次合作 |
| `video_focus` | 短视频优先 | 只邀请新的短视频 |
| `live_focus` | 直播优先 | 只邀请下一场直播 |

模板选择保存在 `config/send-batch.json`。保存后重新计算逐达人意大利语正文、中文辅助、authorization 和 preview hash；冻结时把模板 ID 与最终正文写入不可变 candidate。真实执行只消费冻结正文，不在运行时重新渲染或切换。

本轮只完成代码、只读预览和页面发布；没有冻结批次、启动发送 worker 或发送 TikTok IM。`live_focus` 真实数据只读预览已确认模板、意大利语正文、中文辅助和 authorization 一致。
