# 达人库页面与持久画像刷新

2026-09-12。稳定身份已接入页面，入口为 [达人库](http://127.0.0.1:5198/creators)。当前展示 31 位已核验达人、17 条待解析线索；本轮通过页面完成 1 位意大利达人的真实只读画像刷新。

## 可以使用的流程

- 列表按市场分页，搜索当前名字、历史名字或 OECID；待解析线索独立展示，不计入已核验达人。
- 档案展示稳定 OECID、名字核验时间、平台画像和名字历史。当前无值与历史值分开显示，历史值附原观察时间，不伪装成这次刷新结果。
- 点击刷新画像后，服务端从 creatorId 查出当前身份，冻结 market/OEC。客户端不能指定新 handle、OEC、账号、脚本或文件路径。
- 同一个请求编号幂等；同达人已有 queued/running 任务时归并到该任务。页面关闭或重载后从队列读取状态，未确认的提交保留原请求编号。
- 匹配页面按已有 OEC 展示关联档案，商品候选展开详情后才查询，避免每张卡片立即请求。二发按已保存的来源解析关系展示当前身份，同时保留历史来源名字和原冻结稿。

页面关联不等于业务表改绑：历史 Kalodata 同品记录的归属仍有独立证据要求；matching/second-pilot 原始数据、拒联/控制语义、冻结内容、完成与未知结果均未改写。匹配排序仍依据其原数据集，本轮没有自动改用新观察重跑分析。

## 存储与执行

身份事实库：`var/creator-identities.sqlite`。Web 的身份 GET 使用独立只读连接及短事务，缺库返回 not_imported，不造示例；详情利用已有 market/OEC 历史索引。未来来源量扩大时需为外部来源查询增加复合索引，当前固定 48 条来源不构成万级性能验收。

刷新队列：`var/creator-profile-refresh.sqlite`，状态为 queued/running/completed/blocked。Worker 使用独立心跳、240 秒租约和冻结身份校验；导入期间锁定队列租约，旧 Worker 失去租约后不能再写身份。重启后有完整报告则幂等结算，没有最终报告则记为中断，不自动重复抓取。

每个任务 1 位达人，固定当前已验收的 IT/ACC6 路线，复用现成完整 HTTP 验证和重放。业务请求始终按 OEC，必要时按同 OEC 补身份分型。现有探针 180 秒截止，外层 190 秒留清理时间；身份失败或平台错误记录在任务中，原达人档案不删除。公开错误只返回固定类别，临时签名/验证材料随探针清理。

MX/BR 可查本地已导入资料，但本轮未开放其页面抓取；没有新增 handle 批量导入界面、自动发现排程或真实消息执行。新 Worker 仅消费显式提交的画像刷新任务。

## 运行

在 `apps/web`：

```sh
npm run build
npm run start
```

另一终端持续处理画像刷新：

```sh
npm run identity:worker
```

或在项目根，用现有 Python 环境执行 `scripts/creator-profile-refresh.py worker --once` 只处理一步。CLI 的 enqueue/status/list 接收标准输入 JSON；不接收任意执行命令或配置路径。本轮没有安装系统自启服务，Mac/进程重启后仍需启动 Web 和此 Worker；队列记录留在本机。

当前 Web 只监听 127.0.0.1:5198；Web API 校验本机 Host/Origin、严格字段和请求长度。旧 BDHub 8787、数据库及原发送/预演 Worker 未重启。
