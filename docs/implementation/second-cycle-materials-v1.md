# 二发闭环 B.5：商品短名称、v4话术与卡片预检

2026-09-13。商品级预处理和固定话术预览已实现，现有卡片完成只读核对。不是全部商品卡已准备完毕，未建链或发送。

## 实现

- cycle_materials.py按IT/PID/源标题/策略版本缓存短名称；同商品所有达人复用。佣金与达人变化不触发重新生成；标题变化采取保守失效，后续可以进一步减少纯营销标题变化的重算。
- 模型一次最多处理5商品，只传序号和商品标题，不传达人资料或身份。输出意语短名称、可嵌入句子的短语、中文名称，检查长度、字段、重复引用、营销/承诺词与格式。
- 名称作业先记请求意图，保存响应后再入缓存；重叠批次用商品级预留防重复。请求结果未知不自动重发；已有响应可离线恢复验证。用量与报价估算保存在作业响应，不与早期逐达人草稿实验混合。
- v4有升佣复推、简短邀请、视频/LIVE三套固定表达。填短名称和拟给达人点位，不反复强调BJN新链接、不主动引导索样、不编造爆款或个人历史表现；原文含义使用提高到X%的口径，不说提高了X个百分点。
- 当前v4属于未发送预览，不是冻结发送范围。原v3试点正文/记录保持，前端旧模板折叠、准备按钮禁用，不从旧批准转换新版授权。
- prepare-cycle-materials.py只调用名称模型与两类卡片GET读取。IM精确PID搜索完整翻页，候选最多核对3个列表成员；无法完成核验时标未完成，不自动建卡。
- 匹配条件包含PID、预期列表来源/wire Campaign、成员来源Campaign、实际达人佣金、成员可用状态和库存。核验按offer指纹保存，未来offer变化不复用旧核验；发送前仍需再次读取。
