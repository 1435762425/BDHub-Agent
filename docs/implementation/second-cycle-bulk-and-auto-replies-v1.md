## 自动回复行为

规则优先识别常见问题，未分类文字由DeepSeek返回受校验的问题类型、原文依据和工具要求；不让模型直接授予写权限或编造办理能力。常规回复为已确定业务政策下的短句：

- 二发索样：解释复推、不由机构另寄新样；明确用完/损坏引导询问商家补样，不保证补寄。
- 佣金：只读已确认商品卡并实时查询达人佣金，发送前再核对，不透露机构总额/差额。商品对象不明交人工。
- 链接问题、目录/多诉求、退款样品、图片/不支持内容等：先登记人工事项，再自动发送一次“收到，核对后回复”确认句；同一未结事项不反复发。
- 简单致谢/加橱窗不另发催拍。明确拒联自动保留拒绝标签且不追加确认句；此后达人主动提出服务问题可以服务，不自动恢复营销。
- 事实查询临时失败有限重试，持续失败转人工。Boost不编造解释。图片目前转人工，不自动下载或调用视觉模型。

每条自动回复持久保存唯一requestRef和上下文/控制版本。发送前再次读取会话并同步正文；新消息、编辑、控制改变或暂停会阻止旧回复。超时只核验，不盲目重发；卡文队列和自动回复共享发送锁，未知回复会阻止新的营销提交。正常回复确认后推进服务水位；人工确认句不解除人工接管。
